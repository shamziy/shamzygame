# Love in Lagos on GitHub Pages

This folder is the whole website in ONE file: `index.html`. Nothing else is needed.

1. Make a new GitHub repository (Public).
2. Add file > Upload files (or Create new file named `index.html`) and add `index.html` (and `.nojekyll`). It must be at the top level of the repo.
3. Settings > Pages > Build and deployment > Deploy from a branch > `main` and `/ (root)` > Save.
4. After about a minute open `https://YOUR-NAME.github.io/YOUR-REPO/`

GitHub Pages only hosts websites, so it runs in Demo mode there (pretend people, saved in each visitor's browser).
For real accounts and chat, run the backend on Render or Railway and put its address in the `LIL_API` line inside `index.html`.
